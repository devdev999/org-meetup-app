# UI mockup directions

Scope: full-app interactive prototype, Operate mode. Members browse and join Meetups, manage their Interests and Availability, and use familiar administrative tools. Use fictional data and local state. No visual direction has approval for production.

## Direction contract

THESIS: Compare three complete visual systems at the same route. Atrium translates the supplied architectural reference into Meetup discovery. Fieldwork centres the day's schedule. Studio centres a Member directory and compact editorial index.

OWN-WORLD: Atrium uses warm stone, ivory, charcoal, broad photography and modest rounded corners. Fieldwork uses forest green, pale sage, a narrow utility rail and a time-ordered ledger. Studio uses soft violet, white, aubergine, crisp rectangles and an asymmetric index. All use readable sans-serif controls.

STORY: A Member finds a relevant Meetup, understands the Suggestion, opens its details and tries joining. The same visual system carries profiles, forms and administration. A persistent comparison toolbar changes style without losing the current screen.

FIRST VIEWPORT: Atrium has a horizontal navigation strip, a broad photographic feature and a compact weekly agenda. Fieldwork has a fixed green rail, a wide date heading, activity filters and a time-led list beside an Availability panel. Studio has a compact left directory, a violet introduction beside an untinted photograph, and a dense two-column Meetup index. Primary creation is always visible. Admin replaces discovery with navigation, actionable tables and contextual detail.

FORM: Seed 07a0af09 assigned candidate 7, Studio. Ordered grounded candidates were architectural catalogue, municipal workshop board, museum membership programme, staff common room, park field guide, canteen weekly menu, and civic design studio directory. The user's reference pins Atrium as a required comparison. Fieldwork supplies a distinct schedule-first alternative. The user requested complete mockups before choosing, so selection happens in the finished browser comparison.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Challenger decisions

Jackfield is declined for audience identification and product clarity. Keep its explicit status labels in all tables.

Seven-segment clock is declined on both axes. Keep its stable alignment of times in Fieldwork.

Design annual is competitive on audience identification. Studio keeps its consistent photography and grid discipline, without decorative registration marks or rotating labels.

Camcorder is declined on both axes. Keep an obvious transition between discovery and details.

Rain garden is declined on both axes. Keep distinct activity grouping without simulated physics.

Iridescent cloud is declined on both axes. Keep quiet content fields and one clear selected state.

## Verification

Inspect all styles at desktop and mobile sizes, including discovery, details and administration. Verify switching, navigation, filtering, sample participation, forms, admin decisions and keyboard behaviour. Deliver one draft PR linked to issue #42. Direction selection remains open.
